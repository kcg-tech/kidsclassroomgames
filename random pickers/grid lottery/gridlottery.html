How to Use Grid Lottery

  1. Choose library items or add your own words.
  2. Open the lottery in a separate classroom tab.
  3. Select Pick Next to reveal one covered square.
  4. Continue until every item has been revealed.

Choose Almost Anything

Grid Lottery can be adapted for learners of any age and for many classroom purposes. Use it to choose vocabulary, questions, prizes, teams, activities, classroom jobs, or the next student to participate.

Library Images or Your Own Entries

Select pictures and words from the library for visual learning activities. Type custom entries when you need student numbers or nicknames, classroom chores, lesson tasks, or choices that are specific to your own class.

Make Each Pick Engaging

The teacher will usually control the picker, but a student can press Pick Next in a smaller class. Learners may guess the hidden item or say which one they hope will appear before the square is revealed.

Track What Was Selected

Revealed items remain visible so everyone can check what has already been called. This prevents confusion during longer activities and lets the class review all previous selections at a glance.

Flexible Classroom Display

Display the play page on a projector or shared screen when the whole class needs to follow the same grid. A teacher can also use it on a personal device for a small group or individual activity.

Choose the number of items that suits the available time and purpose of the activity. There is no single recommended classroom set size.
